## 二、建议开发节奏

### 第1步：先定规则和环境

- [ ] 建立 GitHub 仓库，添加5名组员及各自职责。
- [ ] 固定 Python 版本（建议64位 Python 3.11+）、依赖版本和策略参数。
- [ ] 当前已复现设定：510300 ETF；2020-01-02至2026-10-20；20日/60日均线；单边佣金3基点、单边滑点2基点；同一ETF买入并持有作为价格收益基准。
- [ ] 保留策略参数和数据下载日期，避免组员各自使用不同行情区间。

### 第2步：取得并检查真实数据

- [ ] 在可联网的电脑中创建虚拟环境并安装 `requirements.txt`。
- [ ] 运行 `python main.py` 获取真实 ETF 日线；如AKShare接口不可用，使用公开数据源导出CSV后通过 `--csv` 加载。
- [ ] 检查 `outputs/prices.csv` 的日期、开盘/收盘、缺失值及重复日期。
- [ ] 保存数据来源、实际样本起止日期和下载时间。不要把单元测试的合成行情当作实盘历史数据。

### 第3步：验证策略和回测

- [ ] 先运行 `python -m unittest discover -s tests -v`，确保基础测试通过。
- [ ] 本交付包已运行完整历史回测。全样本：策略累计价格收益+5.11%，基准+15.36%，最大回撤-40.95%，夏普0.051；样本外策略+1.53%，基准+4.92%。复权口径未确认，数字不可视为含分红总回报。
- [ ] 若确认了复权口径，应再次运行，并以新生成的 `metrics.csv` 与 Word 报告更新这些数字。
- [ ] 检查 `metrics.csv` 是否包含全样本、样本内、样本外三行。
- [ ] 打开 `equity_curve.png`、`drawdown_curve.png`、`price_moving_averages.png`，确认曲线、回撤和均线图均正常。
- [ ] 查看 `parameter_sensitivity.csv` 和 `annual_returns.csv`，不根据样本外结果事后挑选最优参数。
- [ ] 对比 `backtest_results.csv` 与 `signals.csv`，抽查均线信号是否在下一交易日开盘执行。
- [ ] 可额外比较成本为0、5、10基点的结果，讨论交易成本敏感性；不要只挑选最好的参数作为结论。
