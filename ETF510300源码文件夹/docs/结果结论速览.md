# 结果结论速览（基于实际上传行情）

## 样本与方法
- 标的：沪深300ETF（510300）。
- 样本区间：2020-01-02 至 2026-10-20；1,645 条日线。
- 主策略：20日/60日简单移动平均线；收盘后形成信号，下一交易日开盘执行。
- 基准：同一ETF买入并持有价格序列。
- 成本假设：单边佣金3bp、单边滑点2bp。
- 切分方式：按时间先后，前70%样本内、后30%样本外。

## 主要结果
| 指标 | 全样本 | 样本内 | 样本外 |
|---|---:|---:|---:|
| 策略累计价格收益 | +5.11% | +3.52% | +1.53% |
| 策略年化收益率 | +0.77% | +0.76% | +0.78% |
| 年化波动率 | 13.66% | 12.63% | 15.82% |
| 最大回撤 | -40.95% | -30.36% | -17.22% |
| 夏普比率 | 0.051 | 0.044 | 0.066 |
| 基准累计价格收益 | +15.36% | +9.95% | +4.92% |
| 策略减基准累计收益差 | -10.25个百分点 | -6.43个百分点 | -3.39个百分点 |

## 结论
在当前提供的价格序列和设定成本下，20/60日双均线策略全样本与样本外均未跑赢同标的买入持有价格基准，且全样本最大回撤较深。它的趋势过滤规则简单、可解释，但在震荡行情里可能因滞后与反复切换而受到拖累。课程报告应如实展示这一结果，并将成本敏感性与参数敏感性作为风险讨论，而不是事后挑出全样本收益最高的参数组合。

## 重要限制
原始Excel没有标注前复权、后复权或不复权。当前收益统一称为“所提供价格序列的价格收益”，不能直接写成含现金分红再投资的总回报。确认复权口径后应重新运行并更新所有输出。OHLC结构、日期和末端行情抽查通过不等于历史复权方式已验证。
