# 量化交易技术报告模板（请用实际回测结果填写）

## 封面信息
课程名称：量化交易；小组/组号：____；组长：____；组员：____；GitHub仓库：____；报告日期：____。

## 1. 项目目标
说明要实现一个可运行的量化投资/交易策略、历史回测及基准比较系统。

## 2. 数据来源与清洗
填写数据提供方、文件/接口、标的代码、实际开始/结束日期、交易日数量、复权方式；说明缺失值、重复日期和异常价格如何处理。若数据文件没有标注复权口径，必须明确写“未核验”，不要自行宣称前复权；此时收益是输入价格序列上的价格收益，不是包含分红再投资的总回报。附 `run_metadata.json` 与 `data_quality.csv`。

## 3. 策略逻辑
说明短期/长期均线、持仓信号、次日开盘执行方式、空仓规则和交易成本假设。建议附伪代码或流程图。

## 4. 回测方法
说明收益计算、交易成本、基准选择、样本内/样本外切分原则、年化252交易日及1%年化无风险利率假设。

## 5. 回测结果
插入 `outputs/equity_curve.png`，并将 `outputs/metrics.csv` 的全样本、样本内、样本外指标整理成表格：累计收益率、年化收益率、年化波动率、最大回撤、夏普比率、基准累计价格收益、策略与基准累计收益差。必须说明结果是否包含分红总回报，并使用本组实际运行结果。

## 6. 结果讨论
解释策略是否跑赢基准、样本外是否稳健、回撤情况、市场趋势/震荡对双均线的影响。不要只挑选有利数据区间。

## 7. 稳健性检验
展示成本敏感性、自然年度表现与固定参数组合敏感性。明确这些组合不是用全样本挑选的最终“最优策略”；如需选参，应仅用样本内，并保留样本外作独立验证。

## 8. 局限性与改进
讨论日线成交简化、交易成本估计、滑点、涨跌停和跟踪误差等限制；可提出调整周期、加入风险控制或做成本敏感性分析，但要避免反复试参数后只报告最优结果。

## 9. 复现步骤
写明 Python 版本、依赖安装命令、回测命令、代码仓库版本/提交号、输出文件清单，便于助教复跑。
