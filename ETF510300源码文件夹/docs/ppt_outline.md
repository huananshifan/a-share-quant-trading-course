# 量化交易课程项目PPT页纲（8页，分工版）

> 当前交付包已包含基于组内上传行情文件运行的实际回测输出。演示前建议再次运行测试与回测，并核对 `outputs/run_metadata.json`。复权口径尚未从原 Excel 中确认，因此当前指标按所提供价格序列的价格收益解释，不可表述为含分红再投资的总回报。测试合成行情不是正式成绩。

## 第1页：标题页（组长）
- 课程名称、项目名称：基于沪深300ETF的双均线量化交易策略
- 小组编号、组长、成员姓名
- 汇报日期

## 第2页：研究目标与系统架构（组长）
- 目标：实现一个可运行、有真实数据、有回测结果的投资策略系统
- 架构：数据接入 → 策略/信号 → 回测引擎 → 指标与报告输出
- 用一句话说明为何先从可解释的双均线策略入手

## 第3页：数据来源与处理（组员2）
- 标的：沪深300ETF，代码510300
- 数据来源：小组提供的本地 Excel 日线行情转换为 CSV；实际区间 2020-01-02 至 2026-10-20，共1,645条记录
- 日期/字段质量检查无重复日期、无法解析日期、缺失OHLC或高低价关系异常；末端 2026-10-20 OHLC 与公开行情抽查相符
- 必须注明：原始 Excel 未标注复权口径，因此总回报/分红处理仍需核验；不能写成已确认前复权
- 需要引用的数据：`outputs/run_metadata.json`、`outputs/prices.csv`、`outputs/data_quality.csv`

## 第4页：策略逻辑（组员3）
- 短期均线：20日；长期均线：60日
- 短均线高于长均线 → 下一交易日开盘持有；否则空仓
- t日收盘形成信号、t+1日开盘执行；不在信号产生的同一收盘价成交
- 展示流程图或一段简单伪代码

## 第5页：回测方法（组员3或组长）
- 每日收益拆分为隔夜收益和日内收益
- 默认单边佣金3bp、滑点2bp；仓位变化时计成本
- 基准：同一ETF买入并持有
- 时间顺序切分：前70%样本内、后30%样本外；未据全样本结果选最优参数

## 第6页：主要结果（组员4）
- 插入 `outputs/equity_curve.png`
- 当前全样本策略累计价格收益约 +5.11%，同标的买入持有价格收益约 +15.36%；策略年化收益约 +0.77%，最大回撤约 -40.95%，夏普比率约 0.051
- 样本外策略价格收益约 +1.53%，价格基准约 +4.92%
- 以上均基于提供的价格序列，复权/分红口径未确认；演示时要明确说明策略未跑赢本次价格基准，不夸大结论

## 第7页：交易成本与稳健性（组员5）
- 从 `outputs/cost_sensitivity.csv` 比较零成本、基准成本、双倍成本三种情况：策略累计价格收益约 +7.02%、+5.11%、+3.23%
- 从 `outputs/parameter_sensitivity.csv` 查看窗口组合敏感性：SMA 10/30 样本内收益较高但样本外为 -1.86%；SMA 50/200 样本外为 +25.34% 但样本内为 -4.43%
- 这个反差用于解释过拟合与参数选择风险，不要依据看过的样本外结果再挑选“最优”组合

## 第8页：局限性、结论与改进（组员5，组长统稿）
- 局限：均线滞后、震荡行情反复交易、简化日线成交、未建模涨跌停/整手/盘口/实际券商费率
- 结论必须基于真实数据；不宣称保证未来收益
- 后续改进：优先确认前复权/总回报口径后重跑；再设计只基于样本内的参数选择、滚动样本外检验和风险控制
